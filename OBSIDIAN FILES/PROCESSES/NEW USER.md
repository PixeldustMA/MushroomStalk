What needs to happen to add a new user?

1. LILYPAD MODULE CALLED with mode 'NEW'
2. LILYPAD MODULES passes information to...
	1. FROG where it creates a new save file for the profile
	2. RESIDENT FROG where it sets that new user as the currently active user
	3. FROG LIST where it saves the username and a password for easy look up

What data does this need?

- USERNAME
- PASSWORD
- LOGIN STATUS
- NEWS FILE PATH
